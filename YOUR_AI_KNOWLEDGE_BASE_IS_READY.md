## ⚙️ Technical Details

### Integration Points
- ✅ Backend: `guestChat()` function in aiController.js
- ✅ Frontend: FloatingAIChat component sends requests
- ✅ API: `/api/ai/chat/guest` endpoint (public)
- ✅ Data: Imported from kangaruGirlsKnowledgeBase.js

### Technology Stack
- **Frontend**: React 19, Vite, lucide-react
- **Backend**: Express 5, Node.js
- **Database**: MongoDB (optional - can store conversations)
- **Knowledge Base**: Modular JavaScript export

### Performance
- Instant keyword matching (no AI API calls needed)
- Lightweight responses (no external API latency)
- Scalable (can handle many concurrent users)
- Reliable fallback mechanism

## 🎓 How to Use

### For Visitors (Automatic)
1. Visit the website
2. See floating AI chat button (bottom right)
3. Click to open
4. Ask any question about the school
5. Get instant answers

### For Administrators (Maintenance)

**To Update Information:**
1. Open `/kscbackend/data/kangaruGirlsKnowledgeBase.js`
2. Find the topic you want to edit
3. Update the `response` text or `keywords` array
4. Restart backend server
5. Changes take effect immediately

**To Add New Topic:**
1. Open same file
2. Add new entry to `guestResponses` object
3. Include: keywords array, response text, requiresLogin flag
4. Restart server
